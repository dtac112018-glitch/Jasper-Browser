Version 0.6.6 — Continuous, one-shot desktop chaos
- Desktop icons and previously captured ordinary application windows are re-randomized in a loop while the Jasper Browser profile remains open; every icon cycle ensures it does not intentionally pick the current identical arrangement.
- The desktop-chaos event runs once per Recovery cycle; a consumed marker prevents page reloads or duplicate helper triggers from starting another loop.
- The loop stops when Jasper Browser closes, Escape is pressed, or Recovery requests a stop. The final randomized layout remains until Recovery restores the saved positions.
- Recovery clears the one-shot marker and stop/active flags. The USB runtime passes its own user-local data directory explicitly to the shared desktop-layout worker.
- Pinned taskbar icon order remains unchanged because Windows does not expose a supported, stable runtime API for randomizing it; visible running-app buttons flash instead.
- Static package checks only; confirm real desktop behavior in Windows and check desktop-layout.log if Explorer declines icon moves.

v0.6.4 DESKTOP ICON CAPTURE FIX
--------------------------------
- Fixed the native OpenProcess P/Invoke declaration to load from kernel32.dll. v0.6.3 mistakenly declared it in user32.dll, so desktop-icon capture threw EntryPointNotFoundException and captured zero icons.
- Bumped the desktop-layout snapshot version and aligned the installer, helper health endpoint, launcher, and repair script on JASPER_OK|0.6.4.
- Desktop icon positions are shuffled only after successful capture; Recovery retains the snapshot if positions cannot be restored.
- Pinned taskbar icon reordering remains unsupported; this release does not claim that it physically reorders pinned items.

v0.6.3 DESKTOP-ICON POSITION HOTFIX
-----------------------------------
- Replaced the 16-bit LVM_SETITEMPOSITION message with LVM_SETITEMPOSITION32 and a temporary POINT allocated in Explorer's address space.
- Temporarily clears the desktop list-view LVS_AUTOARRANGE style during icon shuffling, then restores the saved style during Recovery.
- Forces a non-zero rotation of captured icon slots, avoiding a random shuffle that can accidentally leave every icon in its original position.
- Verifies post-move positions and logs icon counts, requests, observed movement, desktop list-view style, and recovery results to %LOCALAPPDATA%\JasperBrowserLite\desktop-layout.log.
- Fixes a stale-snapshot guard that previously exited whenever a v0.6.0 snapshot existed. Old snapshots are restored before creating a fresh snapshot, rather than silently preventing the effect from running.
- Pinned taskbar icon positions remain unchanged; the supported taskbar-side cue is randomized flashing of open-app taskbar buttons. Windows' supported taskbar layout configuration is not an immediate, reversible runtime reorder API.
- Static package checks only; run the repair tool and confirm the desktop log on the target Windows machine.

v0.6.2 HELPER HEALTH-CHECK HOTFIX
----------------------------------

v0.6.1 ADULT-SITE BLOCK + WARNING SHAKE
--------------------------------------
- Added an editable known-adult-domain blocklist and Firefox WebsiteFilter policy. The policy is installation-wide for all profiles using the same Firefox installation; uninstall restores the pre-Jasper policies.json backup.
- Direct adult-site URLs entered in Jasper Search and matching homepage links are intercepted before navigation, replaced with “STOP WHAT ARE YOU DOING”, and launch a bounded native desktop/cursor shake.
- The warning shake lasts up to 5.2 seconds; Escape, the Return button, or Recovery stops it. Open windows are restored to their captured positions when the effect ends. Cursor shaking stops if the user deliberately moves the mouse.
- Typing verity.com into Jasper Search opens the user-provided YouTube link; no video is embedded or bundled.
- Adult-domain matching is a curated blocklist, not a complete category classifier.
- Static checks only; PowerShell/Firefox policy and desktop shaking require Windows testing.

- Added realistic 1920×1080 fire imagery with moving ember particles to the final scene.
- Added an original synthesized scream that rises gradually in volume, followed by a looping digital buffer/glitch tone that stops abruptly when the Jasper window closes or Recovery is used. This imitates a crash; it does not crash Windows.
- Added reversible desktop chaos: desktop icon positions are shuffled among their saved grid positions; visible ordinary application windows on the primary monitor are moved to randomized positions; running-window taskbar buttons flash in randomized order.
- Recovery now attempts to restore saved desktop icon and running-window positions alongside the original wallpaper. Windows does not offer a stable supported API to reorder pinned taskbar icons, so their persistent pinned order is intentionally left unchanged.
- Added an early Linux alpha port package with a user-local launcher and recovery script; system-specific Linux desktop effects are not yet at Windows parity.
- Static validation only in this environment; execute the PowerShell installer and desktop effects on Windows to verify behavior.
